ygd-editor

Git worktrees and AI agent sessions, side by side. macOS, Windows and Linux.

Looking up the latest release…

First launch on macOS

  • Open the .dmg and drag ygd-editor to Applications.
  • macOS says the developer is unidentified: right-click the app → Open once, or allow it under System Settings › Privacy & Security.
  • Apple Silicon and Intel builds are separate downloads.

First launch on Windows

  • Run the installer. SmartScreen shows “Windows protected your PC”: More info → Run anyway.
  • The publisher reads ygd-editor release signing; the thumbprint to compare is below.

First launch on Linux

  • AppImage: chmod +x ygd-editor-*.AppImage, then run it.
  • Debian/Ubuntu: sudo apt install ./ygd-editor-*.deb.

Is this download genuine?

Nobody paid Apple or Microsoft for a certificate, so the operating systems show their unidentified-developer prompt. Those prompts say nothing about tampering; these two checks do.

Provenance. Every release ships SHA256SUMS.txt signed with Sigstore by the project's release workflow itself. With cosign installed:

cosign verify-blob --bundle SHA256SUMS.txt.sigstore.json \
  --certificate-identity-regexp '^https://github.com/MHGuitarte/ygd-editor/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS.txt
sha256sum --check --ignore-missing SHA256SUMS.txt   # shasum -a 256 -c on macOS

Code signature. The macOS app and the Windows installer are signed with the project's own certificate (public key). Compare the fingerprint, not the name — anyone can name a certificate anything:

SHA-256 46:C5:62:27:2A:5C:22:9E:D7:85:E1:A3:0D:47:2A:A3:5B:CE:AC:F0:7D:E4:D8:A3:49:23:C9:7B:D3:74:C3:AB
SHA-1 (macOS codesign, Windows thumbprint) 79A40643BDFE500AB6730154B03B336C1809C57C

# macOS
codesign --verify --deep --strict /Applications/ygd-editor.app && codesign -dvv /Applications/ygd-editor.app 2>&1 | grep Authority
# Windows (PowerShell)
(Get-AuthenticodeSignature .\ygd-editor-*-setup.exe).SignerCertificate.Thumbprint

Updates

The app checks this repository shortly after launch, downloads a new version in the background and offers “Restart to update”. Settings › Notifications also has a manual check and an option to install updates by itself when nothing is running.
