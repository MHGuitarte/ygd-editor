ygd-editor
Download Handbuch Alle Versionen Problem melden

Gib jeder Aufgabe ihren eigenen Branch und ihren eigenen KI-Agenten – und behalte alle im Blick.

ygd-editor öffnet jede Aufgabe in einem eigenen Git-Worktree, führt darin einen Coding-Agenten aus (Claude Code, Codex oder Gemini CLI) und lässt dich die Änderungen prüfen, committen, pushen und den Pull Request öffnen, ohne das Fenster zu verlassen. Kostenlos, für macOS, Windows und Linux.

Neueste Version wird gesucht…

Was du bekommst

Ein Worktree pro Aufgabe

Jeder Branch bekommt seinen eigenen Ordner: Agenten kommen sich nie in die Quere, und du wechselst die Aufgabe, ohne irgendetwas zu stashen.

Agenten dort, wo der Code ist

Starte Claude Code, Codex oder Gemini CLI in einem Worktree, sieh ihm bei der Arbeit zu, beantworte seine Fragen und übergib eine Sitzung an einen anderen Worktree, wenn sich die Pläne ändern.

Prüfen und ausliefern an Ort und Stelle

Dateien stagen, den Diff lesen, den Agenten bitten, eine Auswahl zu erklären oder zu ändern, committen, pushen und den Pull Request öffnen – alles auf demselben Bildschirm.

Steht dir nicht im Weg

Ein einziger Posteingang für alle Sitzungen, die auf dich warten, optionale Desktop-Benachrichtigungen und eine Anzeige der heutigen Ausgaben mit Limits, die du selbst setzt.

In einer Minute installiert

Dein Computer wird dich beim ersten Mal warnen. Das ist zu erwarten: Niemand hat Apple oder Microsoft für ein Zertifikat bezahlt, und die Warnung betrifft diesen fehlenden Papierkram, nicht das, was die App tut. So kommst du daran vorbei – einmal, und nie wieder auf diesem Computer.

macOS

  1. Öffne die heruntergeladene .dmg. Ein Fenster zeigt diese Schritte in deiner Sprache – klick auf Weiter – und zieh dann ygd-editor in den Ordner „Programme“.
  2. Öffne sie. macOS sagt, die App konnte nicht überprüft werden, und bietet In den Papierkorb legen oder Fertig an: Klick auf Fertig.
  3. Öffne Systemeinstellungen › Datenschutz & Sicherheit, scrolle nach unten zu Sicherheit und klick neben ygd-editor auf Dennoch öffnen. Bestätige mit deinem Passwort. Das war’s – macOS fragt nicht noch einmal.
  4. Unter macOS 14 oder älter erledigt Rechtsklick auf die App › Öffnen dasselbe in einem Schritt.
  5. Nicht sicher, welchen Mac du hast? Apple-Menü › Über diesen Mac: „Apple M…“ ist Apple Silicon, alles mit „Intel“ ist Intel.

Windows

  1. Starte den Installer. Wenn SmartScreen „Der Computer wurde durch Windows geschützt“ meldet, klick auf Weitere Informationen und dann auf Trotzdem ausführen.
  2. Als Herausgeber steht dort ygd-editor release signing – das sind wir. Wähle bei Bedarf den Installationsordner und schließe ab.
  3. Die App erscheint im Startmenü als ygd-editor.

Linux

  1. AppImage: mach sie ausführbar (chmod +x ygd-editor-*.AppImage) und starte sie. Wenn sie sich über FUSE beschwert, starte sie mit --appimage-extract-and-run.
  2. Debian / Ubuntu: sudo apt install ./ygd-editor-*.deb, dann findest du sie im Anwendungsmenü.

Was du brauchst

Git auf deinem Computer und ein Konto bei mindestens einem Anbieter. Codex und Gemini CLI stecken nicht im Installer — deshalb ist er klein —: die App lädt den, den du wählst, beim ersten Aufruf herunter (etwa 100 MB für Codex, 20 MB für Gemini CLI) und prüft ihn gegen die Version, mit der dieses Release gebaut wurde, bevor sie ihn ausführt; für Claude Code, dessen Lizenz das Mitliefern nicht erlaubt, bietet Einstellungen › KI-Anbieter einen Klick, der Anthropics offiziellen Installer für dich ausführt. Einen Anbieter zu verbinden öffnet dessen Anmeldeseite in deinem Browser. Für Pull Requests: gh von GitHub oder glab von GitLab.

Updates kümmern sich um sich selbst

Kurz nach dem Start sucht die App nach einer neuen Version, lädt sie still herunter und bietet „Neu starten und aktualisieren“ an. Einstellungen › Benachrichtigungen hat außerdem einen Button „Nach Updates suchen“ und, wenn du magst, eine Option, Updates von selbst zu installieren, wenn nichts läuft. Nach einem Update sagt dir die App, auf welcher Version du bist, und verlinkt, was sich geändert hat.

Neu hier?

Das Benutzerhandbuch führt durch die ersten zehn Minuten: ein Repository öffnen, einen Worktree anlegen, einen Agenten starten, das Ergebnis prüfen und ausliefern.

Ist mein Download echt?

Zwei unabhängige Prüfungen, von denen keine darauf beruht, einem Namen zu vertrauen. Du musst sie nicht durchführen; sie sind für die da, die es wollen.

Ist mein Download echt? — die technischen Details

Herkunft. Jede Version kommt mit SHA256SUMS.txt, signiert über Sigstore vom Release-Workflow des Projekts selbst. Mit installiertem cosign:

cosign verify-blob --bundle SHA256SUMS.txt.sigstore.json \
  --certificate-identity-regexp '^https://github.com/MHGuitarte/ygd-editor(-app)?/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS.txt
sha256sum --check --ignore-missing SHA256SUMS.txt   # macOS: shasum -a 256 -c SHA256SUMS.txt

Code-Signatur. Die macOS-App und der Windows-Installer sind mit dem Zertifikat des Projekts signiert (öffentlicher Schlüssel). Vergleiche den Fingerabdruck, nicht den Namen – jeder kann ein Zertifikat nennen, wie er will.

SHA-256 46:C5:62:27:2A:5C:22:9E:D7:85:E1:A3:0D:47:2A:A3:5B:CE:AC:F0:7D:E4:D8:A3:49:23:C9:7B:D3:74:C3:AB SHA-1 (macOS codesign · Windows thumbprint) 79A40643BDFE500AB6730154B03B336C1809C57C 
# macOS
codesign --verify --deep --strict /Applications/ygd-editor.app && codesign -dvv /Applications/ygd-editor.app 2>&1 | grep Authority
# Windows (PowerShell)
(Get-AuthenticodeSignature .\ygd-editor-*-setup.exe).SignerCertificate.Thumbprint
